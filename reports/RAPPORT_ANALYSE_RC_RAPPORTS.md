## 3. ANALYSE DES ÉCARTS

### Écart 1: DGFiP - Montant du marché
| Aspect | Valeur |
|--------|--------|
| **Critère concerné** | Montant estimé / maximum |
| **Valeur dans RC** | Montant max : 1 200 000 € HT (1 440 000 € TTC). Montant estimé : 480 000 € TTC |
| **Valeur rapport v1/v2/v3** | 400 000 € HT (valeur estimée et valeur maximale de l'accord-cadre) |
| **Nature de l'écart** | **SIGNIFICATIF** |
| **Analyse** | Le rapport indique "400 k€ HT" comme valeur unique. Le RC distingue : (1) Montant estimé sur durée totale : 480 000 € TTC (soit ~400 000 € HT), (2) Montant maximum/plafond : 1 200 000 € HT. L'écart entre estimation et plafond est de 3x. |
| **Impact opérationnel** | Le rapport sous-estime le plafond contractuel. Un candidat pourrait être éliminé si son offre dépasse 400 k€ alors que le plafond réel est 1,2 M€. Inversement, une stratégie basée sur 400 k€ pourrait manquer des opportunités sur la partie variable. |
| **Recommandation** | Mettre à jour le rapport pour refléter le plafond réel de 1,2 M€ HT et l'estimation de 480 k€ TTC (~400 k€ HT). |

### Écart 2: EPPGHV - Structure du montant
| Aspect | Valeur |
|--------|--------|
| **Critère concerné** | Montant global vs montant AC |
| **Valeur dans RC** | Marché composite : prix global forfaitaire (infogérance) + AC bons de commande (max 160 000 € HT) |
| **Valeur rapport v1** | "~660 000 € HT (accord-cadre à bons de commande — montant max : 160 000 € HT)" |
| **Nature de l'écart** | **AMBIGU** |
| **Analyse** | Le rapport mentionne "~660 k€" puis entre parenthèses "montant max AC : 160 k€". Cette formulation est ambiguë : les 660 k€ correspondent probablement à la partie forfaitaire (infogérance) + 160 k€ AC, soit ~820 k€ total. Le rapport signale d'ailleurs une "incohérence à signaler — montant". |
| **Impact opérationnel** | Risque de sous-estimation du chiffrage si le candidat ne comprend pas la dualité forfaitaire/AC. Le rapport a raison de signaler cette ambiguïté. |
| **Recommandation** | Préciser dans le rapport que le montant global comprend : (1) une partie forfaitaire pour l'infogérance (~660 k€), (2) une partie AC à bons de commande (max 160 k€). Total : ~820 k€ HT. |

## ANNEXE - Méthodologie de l'analyse

### Principes suivis
1. **Distinction extraction/interprétation:** Les faits extraits des documents sont distingués des analyses et hypothèses.
2. **Traçabilité:** Chaque métadonnée est rattachée à sa source documentaire (RC ou rapport).
3. **Hiérarchisation des écarts:** Les écarts sont classés par nature (mineur, ambigu, significatif, bloquant).
4. **Preuve documentaire:** Aucune conclusion n'est émise sans appui sur un document lu.

- **Rapports:** 3 versions (rapport_marches_publics_2026, _v2, _v3)
- **RC:** 6 fichiers PDF extraits en texte
