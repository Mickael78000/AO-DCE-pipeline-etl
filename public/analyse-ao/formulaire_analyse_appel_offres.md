# Formulaire d’analyse manuelle d’un appel d’offres

## Identification du marché

| Critère | Rôle dans l’analyse | Valeur à renseigner | Observations / commentaire analyste |
|---|---|---|---|
| reference | Identifie le marché de façon unique |  |  |
| titre | Donne le contexte métier principal |  |  |
| acheteur | Permet de qualifier le profil de l’acheteur |  |  |
| type_acheteur | État, collectivité, établissement public, etc. |  |  |
| type_marche | Services, fournitures, travaux, indéterminé |  |  |
| montant_estime | Permet d’évaluer l’ordre de grandeur économique du besoin |  |  |
| date_limite_remise_offres | Critère obligatoire pour la lecture du marché |  |  |
| url_marche | Permet de retrouver la source et de vérifier les informations |  |  |
